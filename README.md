# 特級呪物神経衰弱 (Curse Creatures Cards Match)

GitHub Pages上でサクッと手軽に遊べる、レスポンシブ対応の神経衰弱サイトです。

## 概要
配信上で産み出された特級呪物たちをテーマにした23枚の素材画像を利用し、完全ランダムな配置で神経衰弱を楽しめます。
プレイヤーは5段階の難易度から選択してタイムアタックに挑戦し、クリアタイムの記録保持やX（旧Twitter）へのシェアが可能です。

## フォルダ構成
```
curse-creatures-cards-match/
├── index.html
├── style.css
├── main.js
├── README.md
└── images/
    ├── 1.jpg～23.jpg
    └── back_of_card.jpg
```

## 機能・特徴
1. **5段階の難易度設定**
   - 8枚 (4ペア), 12枚 (6ペア), 16枚 (8ペア), 24枚 (12ペア), 32枚 (16ペア) から選択可能。
   - 23種類の画像からランダムに必要なペアが自動抽出され、完全にシャッフルされます。
2. **タイムアタック & ローカル記録保存**
   - ゲーム開始と同時にタイマーが作動。
   - 難易度ごとに**ベスト3**のタイム記録をブラウザの `LocalStorage` に保存。
3. **スマートフォン対応 (レスポンシブ)**
   - PC、タブレット、スマホそれぞれの画面幅に合わせて、カードのグリッドサイズや列数を自動で最適化。
4. **X（旧Twitter）共有**
   - クリアタイムをXに即座にポスト可能。
